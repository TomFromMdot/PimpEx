# Components

An actor (GameObject) is a name plus a set of components. A component is data:
how the actor looks, how it moves, what it stores. Behaviour is added in Lua
(`<Behavior>`, docs/behaviors.md) or in `.swap` (`PROC ... FOR Component`).

```xml
<Actor name="Player" x="100" y="200" w="32" h="32" tags="hero">
  <Rect color="blue"/>
  <Collider/>
  <Health hp="5"/>                      <!-- a component from components.xml -->
  <Behavior name="topdown_move" speed="4"/>
</Actor>
```

- `Transform` and `Body` fields can be written directly on `<Actor>` (`x="10" vx="2"`).
- In `.swap` and Lua a field is `Actor.field` (shortcuts: `x`, `vx`, `rotation`...)
  or `Actor.Component.field`, e.g. `Player.Health.hp`, `Cam.Camera.zoom`.
- A missing component is added on the first `SET`.
- This file is generated by `pimpex components --markdown`. In a project with
  `components.xml` the command also lists the user components.

## User components: `components.xml`

```xml
<Components>
  <Component name="Health" doc="Hit points">
    <Field name="hp" type="number" default="3"/>
    <Field name="shield" type="bool" default="false"/>
  </Component>
</Components>
```

Field types: `number`, `integer`, `bool`, `text`, `color`.

## Built-in: general

### `<Transform>`

Position, size, rotation and visibility. Every actor has it; its fields can be written directly on <Actor>.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `x` | number | `0` | X position (centre) |
| `y` | number | `0` | Y position (centre); grows down in 2D, up in 3D |
| `z` | number | `0` | Z position (3D) |
| `w` | number | `32` | width |
| `h` | number | `32` | height |
| `d` | number | `32` | depth (3D) |
| `rx` | number | `0` | rotation around X in degrees (3D) |
| `ry` | number | `0` | rotation around Y in degrees (3D) |
| `rz` | number | `0` | rotation around Z in degrees (the 2D rotation) |
| `scale` | number | `1` | scale (3D, models) |
| `layer` | integer | `0` | 2D drawing order (higher = on top) |
| `visible` | true/false | `true` | whether the actor is drawn |
| `space` | world \| screen | `world` | world = in the world, screen = HUD in screen pixels |

## Built-in: movement

### `<Body>`

Velocity and gravity. The engine moves the actor every frame.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `vx` | number | `0` | X velocity per frame |
| `vy` | number | `0` | Y velocity per frame |
| `vz` | number | `0` | Z velocity per frame (3D) |
| `gravity` | number | `0` | downward acceleration per frame (e.g. 0.5) |
| `grounded` | true/false | `false` | 1 when standing on something solid (read-only) |

### `<Collider>`

Collisions with the actor's box (w, h, d).

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `kind` | solid \| trigger | `solid` | solid = cannot be walked through, trigger = only detects touches |

## Built-in: 2D

### `<Rect>`

Rectangle w × h.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `color` | color | `white` | color |

### `<Circle>`

Circle with diameter w.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `color` | color | `white` | color |

### `<Sprite>`

Image from <Resources> stretched to w × h.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `texture` | text | `""` | texture id from <Resources> |
| `tint` | color | `white` | tint (white = unchanged) |

### `<Text>`

Text. {Actor.field} inserts a live value. In 3D scenes text usually has space="screen".

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `value` | text | `""` | the text |
| `size` | integer | `20` | font size |
| `color` | color | `white` | color |

## Built-in: 3D

### `<Cube>`

Box w × h × d.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `color` | color | `white` | color |
| `wire` | true/false | `false` | true = edges only (wireframe) |

### `<Sphere>`

Sphere with diameter w.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `color` | color | `white` | color |
| `wire` | true/false | `false` | true = edges only (wireframe) |

### `<Cylinder>`

Cylinder: diameter w, height h.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `color` | color | `white` | color |
| `wire` | true/false | `false` | true = edges only (wireframe) |

### `<Plane>`

Flat floor w × d.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `color` | color | `white` | color |

### `<Model>`

3D model (.glb, .gltf, .obj) from <Resources>.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `model` | text | `""` | model id from <Resources> |
| `tint` | color | `white` | tint |

## Built-in: camera and light

### `<Camera>`

Camera. Position from the actor's Transform. The first active camera in the scene is used.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `mode` | fixed \| follow \| orbit \| fps | `fixed` | fixed | follow (2D and 3D), orbit | fps (3D) |
| `target` | text | `""` | actor to follow / look at |
| `zoom` | number | `1` | zoom (2D) |
| `fov` | number | `60` | field of view in degrees (3D) |
| `distance` | number | `8` | distance from the target (3D follow/orbit) |
| `height` | number | `4` | height above the target (3D follow/orbit) |
| `active` | true/false | `true` | whether this camera is used |

### `<Light>`

Light in a 3D scene (max 4). Position from Transform.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `kind` | point \| directional \| ambient | `point` | point = bulb, directional = sun (shines from its position to (0, 0, 0)), ambient = ambient light (no direction) |
| `color` | color | `white` | light color |
| `intensity` | number | `1` | brightness |
